# Fuentes locales

Montserrat y Dancing Script: archivos variables WOFF2 para pesos 400–700 y subconjuntos latin/latin-ext. Los acentos del español están incluidos. Fuentes descargadas desde fonts.googleapis.com / fonts.gstatic.com el 6 de octubre de 2026. Licencias completas junto a los archivos. No modificar la atribución o nombres reservados.

OFL originales:
- https://github.com/google/fonts/blob/main/ofl/montserrat/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/dancingscript/OFL.txt

La nueva composición incorpora Montserrat Black 900 en archivos WOFF2 latin/latin-ext separados. Comparte la licencia Montserrat-OFL.txt. Solo se asigna a títulos y botones de las secciones rediseñadas.
